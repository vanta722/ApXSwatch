# ModBand Atelier Landing Page

Demand-test landing page for a no-logo premium integrated bracelet concept.

## Local dev
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
1. Push this folder to GitHub.
2. Import the GitHub repo into Vercel.
3. Vercel should detect Vite automatically.
4. Build command: `npm run build`
5. Output directory: `dist`

## Positioning
Independent aftermarket integrated bracelet concept. No AP, Swatch, or protected brand logos.
