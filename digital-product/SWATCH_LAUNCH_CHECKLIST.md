# The Hype Watch Launch Checklist
## A fast buyer prep guide for limited watch drops

**Price:** $5 digital download  
**Purpose:** Help buyers prepare before launch day, avoid scams, and move fast when the drop opens.

---

## Important Note
This guide is independent and informational. It is not affiliated with, endorsed by, or sponsored by Audemars Piguet, Swatch, or any related brands.

---

## 1. Before Launch Day

### Confirm the Drop
- [ ] Confirm official release date from brand-owned channels
- [ ] Confirm official store list or online checkout method
- [ ] Save links to official pages only
- [ ] Avoid random “early access” links from comments or DMs
- [ ] Screenshot official product details, price, and rules

### Set Your Budget
- [ ] Decide your max retail spend
- [ ] Decide your max resale spend, if you miss retail
- [ ] Include tax, shipping, travel, gas, parking, and platform fees
- [ ] Do not chase emotional FOMO pricing

### Choose Your Target
- [ ] Pick your first-choice color/model
- [ ] Pick two backup colors/models
- [ ] Know which styles have the strongest resale demand
- [ ] Know which styles you personally would keep if resale slows

---

## 2. Account + Payment Setup

### Online Drop Prep
- [ ] Create/update account on official site if needed
- [ ] Save shipping address
- [ ] Save billing address
- [ ] Use fast payment method: Apple Pay, Shop Pay, PayPal, or saved card
- [ ] Test checkout on another item if possible
- [ ] Turn off VPN if checkout blocks it
- [ ] Use stable Wi-Fi or strong mobile data

### In-Store Drop Prep
- [ ] Confirm store opening time
- [ ] Confirm purchase limits
- [ ] Bring valid ID
- [ ] Bring backup payment card
- [ ] Bring portable charger
- [ ] Bring water/snacks if lining up
- [ ] Know parking/transit plan

---

## 3. Launch Day Game Plan

### 30 Minutes Before
- [ ] Phone charged above 80%
- [ ] Laptop ready if online
- [ ] Payment method ready
- [ ] Official link open
- [ ] Backup device ready
- [ ] Group chat muted unless helping
- [ ] Do not click random links

### At Drop Time
- [ ] Refresh carefully, not wildly
- [ ] Add first-choice item to cart
- [ ] Checkout immediately
- [ ] Do not browse too long
- [ ] If first choice fails, move to backup instantly
- [ ] Screenshot confirmation page
- [ ] Save order email

---

## 4. Scam Avoidance

### Red Flags
- [ ] Seller has no proof of purchase
- [ ] Seller refuses timestamped photos/video
- [ ] Seller only accepts Zelle, Cash App, crypto, or friends/family payments
- [ ] Price is far below market
- [ ] Photos look reused or AI-generated
- [ ] Box/papers look inconsistent
- [ ] Seller rushes you aggressively

### Safer Buying Rules
- [ ] Use buyer-protected payment when possible
- [ ] Ask for timestamped video
- [ ] Ask for receipt/order confirmation with sensitive info hidden
- [ ] Compare details against official photos
- [ ] Check seller history
- [ ] Avoid deals that feel too convenient

---

## 5. Flip Math Sheet

Use this before buying for resale:

**Expected sell price:** $_____  
**Purchase price:** $_____  
**Tax/shipping/travel:** $_____  
**Marketplace fee:** $_____  
**Shipping to buyer:** $_____  
**Payment fee:** $_____  
**Expected profit:** $_____

If the real profit is not worth the time/risk, pass.

---

## 6. Resale Exit Plan

### Possible Exit Channels
- [ ] eBay sold listings
- [ ] StockX/GOAT if accepted
- [ ] Facebook watch groups
- [ ] Reddit watch exchange communities
- [ ] Local buyer meetups in safe public places
- [ ] Instagram/TikTok audience

### Listing Prep
- [ ] Take clear photos in natural light
- [ ] Show box, receipt/proof, watch front/back
- [ ] Include timestamp photo
- [ ] State condition honestly
- [ ] State shipping/payment terms clearly
- [ ] Keep communication professional

---

## 7. Accessory Opportunity Checklist

If you own the watch or can inspect one:

- [ ] Measure case width at bracelet/strap connection
- [ ] Measure pin/screw width
- [ ] Measure case curvature
- [ ] Photograph side profile
- [ ] Photograph underside
- [ ] Photograph strap connection close-up
- [ ] Note whether the strap/bracelet is removable
- [ ] Note tools required

These measurements help accessory makers build better aftermarket bracelets, straps, protectors, and cases.

---

## 8. Launch Day Rule

Move fast, but do not move blind.

The goal is not to buy because everyone is loud.  
The goal is to buy when the numbers, authenticity, and exit plan make sense.
